uses the standard library and bpy. Comparison boards require Python >=3.11
and Pillow (`python3 -m pip install -r blender/requirements-review.txt` in your own environment,

## Rebuild and render

From the repository root, with the supported Blender executable on PATH:

```sh
blender --background --factory-startup --python-exit-code 1 --python blender/scripts/build.py
blender --background --python-exit-code 1 --python blender/tests/validate.py
blender --background --python-exit-code 1 --python blender/scripts/render.py -- --target leo --samples 24 --size 640
blender --background --python-exit-code 1 --python blender/scripts/render.py -- --target s05 --samples 24 --size 960
blender --background --python-exit-code 1 --python blender/scripts/render.py -- --target rig --samples 16 --size 640
blender --background --python-exit-code 1 --python blender/scripts/render.py -- --target benchmark --samples 24 --size 640
python3 blender/scripts/compare.py
```

Build overwrites only the three prototype .blend outputs. It starts from an
empty scene for each library and resets a separate deterministic seed per asset.
Do not run builders against production .blend files. Renders overwrite their
named review PNGs and per-target manifests, recording elapsed times and hashes.
Use `--python-exit-code 1` so Blender reports Python failures as shell failures.
The `--size` argument is width, square for diagnostics, 16:9 for Scene 05.
These small review PNGs are intentional, not final video endpoints.
Build checks all captured authority hashes before creating geometry and stops
if they changed; review the new authority before updating the extraction/config.

To pose Leo in Blender's Python console, resolve the repository dynamically and
import `apply_pose` from `blender/scripts/poses.py`, then call
`apply_pose(bpy.data.objects['Leo_RIG'], 'lie')`. Supported presets: `neutral`,
`walk`, `lie`, `struggle`, `head_turn`. Animate `CTRL_front_L/R` and
`CTRL_hind_L/R` for planted paw placement; poles control knee direction.
`hips`, `spine`, `chest`, `neck`, `head` and three tail bones provide basic
body articulation. There is no approved walk cycle or net simulation.

## Spatial, camera and color conventions

Z up, +Y into set, X right in wide view. One Blender unit = **0.2 m**; Leo is a
miniature roughly 0.28 m high. Ground origin is the clearing center at Z=0;
registered support objects begin `SUPPORT_`. Water, mound, rock tops and foliage
are invalid default support. Milo proxy is exactly .25 of measured neutral Leo
height, hidden from beauty and explicitly non-production.

Wide camera: provisional perspective fit, 39 mm, position (0,-13,3.5), target
(0,4,1.55). Lens/shift variants preserve its optical center and reflect current
normalized plate crops. Repeated centers share a family; p02 and p04 retain
separate offsets because their source crops differ. Perspective depth is an
interpretation of a single image, not recovered ground truth.

Cycles CPU, 24 samples with denoising for review. Standard view transform,
look None, exposure 0, gamma 1; RGB PNG, sRGB output. Materials are native linear
RGB approximations, not measured pigment reflectance. Cool dusk sky/neutral
fill, limited far-left warm key; no global amber grade. Studio uses neutral
soft area lights. Short sparse curve fibers, fine bump, noise color variation,
roughness .91 and sheen .18; no hair simulation.

## Limitations and approval

The rig is an articulated feasibility rig: torso is voxel-welded with blended
spinal weights; limbs and facial parts retain overlapping components with
rigid segment weights. It needs continuous quad retopology and deformation
polish before final animation. Mane curls, muzzle depth, ear integration and
wool density still differ from the 2D canonical. Presets demonstrate control
range, not finished performances. The environment is a coarse reconstructed
set with simplified foliage and provisional camera matching. Reference renders
are comparison evidence, not approval or a claim of success. Only the owner
can approve a canonical replacement. Continue within Leo/Scene 05 before Milo
or story-wide conversion.
