## Boundaries

The new checker reads supplied metadata and hashes local files only. It cannot decide actual legal rights, verify a creator's ownership, parse license meaning, assess visual quality, authenticate an owner decision, scan Blender code, download assets, authorize spending or publish anything. It always returns production_approved=false.

The five provider catalogs/license pages were researched through official web sources. No third-party asset downloads, account logins, new MCP installations, paid calls, actual Blender imports/renders, .blend edits, Git changes or local-Mac updates were performed for this release. Native Blender helpers still require local runtime validation. Do not carry forward a prior scene-inspection claim as a new inspection of the user's latest scene.
