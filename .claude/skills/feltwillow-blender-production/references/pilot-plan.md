# Pilot plan: staged evidence, not a full-story rebuild

## Pilot 0: integrate this skill safely

Inspect local checkout and unpushed `blender/` work. Read current owner decisions. Verify available tools without generation or scene changes. Make a task brief with a fixed spend cap of zero until a paid request is separately approved. Produce the authority and dependency report. Preserve accepted 2D images, audio and the existing Wan production path.

## Pilot 1: Leo shape and motion feasibility

Use the existing successful Tripo H3.1 candidate as provided. Audit the actual model, not only its turntable. Compare front, sides, rear and underside with current Leo canon. Investigate user-reported left-whisker absence and rear-mane construction as focused candidate repairs. Preserve successful face/body design.

Try a minimal rig and three diagnostic actions: head turn, planted-paw transfer, and lying/rising transition. Keep clay/material-simple previews first. Record deformation failure regions and the effort actually spent. The "one-hour" influence is a time-boxed triage experiment: after the agreed budget, return a usable diagnosis even if the hero is not ready. Do not promise a complete production actor within sixty minutes.

## Pilot 2: one felt patch and mode-appropriate S05 still

Keep the selected mesh. Test native Blender felt first, then one PATINA swatch only with approval if it addresses an observed deficiency. Preserve canonical color regions. Add sparse fibers only after base material and deformation work.

Build the Great Tree environment as a camera-aware 3D/2.5D set. Declare the design mode. Match an existing S05 view only in `plate_match`; otherwise establish a rich, readable new candidate view guided by the existing artwork. Maintain a supported resting Leo and unchanged character scale. Block the future Milo contact route with a correctly scaled, clearly labeled proxy if the full model is unavailable. Do not present the proxy as a canonical mouse.

Produce: reference/candidate comparison; clay and felt passes; camera/invariant sheet (old-image landmark residuals only for `plate_match`); a normal-light and dusk test; simple memory/time measurements. Stop at owner review before building every view.

## Pilot 3: quiet S05 sequence

Choose a story-compatible 3-5 second test: resting Leo breathes subtly, then a restrained head/eye reaction as the story permits. A motion test unrelated to the exact story may still be useful, but label it non-production. Include only a few low-amplitude leaf/grass cues. No need for new dialogue generation, full net simulation, or full-film export.

Render with the proposed final frame rate/color settings, inspect the full sequence and test a genuine shared-state continuation. Compare to current source images; do not declare success only because it renders. An optional Wan experiment later needs a real supported conditioning path, not just I2V named as stylization.

## Pilot 4: generalization beyond Leo

Before claiming a general fable pipeline, test a bird profile and a human/upright profile. For a bird: fold/extend wings, perch and land; add a waterline test for a duck if the next story needs it. For a human: seated posture plus hand-to-prop grasp/release and a facial hold. Use existing approved story characters where available rather than inventing production canon.

Add reptile, fish, shell, insect or hybrid tests when a real story requires them. The skill offers their planning/checklists now; it does not include ready-made meshes/rigs for every species. Build reusable templates from successful tests, not from unverified universal assumptions.

## Pilot 5: environments and delivery

Validate a second location, such as stream or trap, with interaction and ambient continuity. Test the most difficult transition: entering water, knot release, doorway carrying, branch contact or world-state change. Only then consider full asset-library work or HPC rendering. Carry actual time/memory measurements into a production budget.

## Stop/go decisions

Continue when recognizable canon, felt look, manageable deformation and mode-appropriate set quality are demonstrated at the intended camera distance. Pause and change technique when the same critical defect survives the bounded repair budget. Preserve promising assets; do not start a new generation cycle merely because the workflow changed tools.

A reasonable first release of this skill is a research-grounded operating system for these pilots. Calling it "perfect" before those pilots would hide the actual uncertainty. Add measured local results and owner decisions to later versions.
