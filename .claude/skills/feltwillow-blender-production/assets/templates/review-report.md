Task, story, file/revision/hash, source/dependency hashes, current commit, tool versions.

## Scope and changes
What changed; what was preserved; which property authorities were used.

## Evidence
Actual renders/playback/measurements and exact commands, exit status and logs.
Label claims source-verified, metadata-tested, visually observed, owner-selected, hypothesis or not tested.

For each: ID, severity, file/hash, frame/time, defect, affected contract, proposed bounded correction.
