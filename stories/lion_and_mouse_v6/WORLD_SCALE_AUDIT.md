## What is covered and what was missing

Existing rules already bind canonical identity/material, plate/crop, physical
scale, setup anchors, grounding, prop state, mouth policy and exact approvals.
They also define strong upper-body speaker portraits. However, the source
staging still contains instructions such as “keep him small within the wide
landscape”; `keyframe_plan.build` renders physical height and placement without
selecting whose world should carry the beat. Thus correct geometry can still
produce an unreadable subject. The scoped s09_p02 mouse-world exception is
already present and must be retained, not invented anew.

The new [generic policy](../../docs/perceptual-world-staging.md) separates
anatomy from audience scale. The [story policy](PERCEPTUAL_WORLD_POLICY.md)
provides defaults, warning floors, exceptions, generation workflow, minimal
metadata decision and exact future builder patch points. It preserves the
successful Leo-only language and existing approval foundations.

  for Milo’s own explanation. This is detail/attention imbalance, not proof of
  missing source pixels or an incorrect same-depth ratio.
- **Scene 04:** the current owner-selected revisions still make Milo a small
  travel figure. Classify as a future composition issue; retain final accepted
  bytes. Use s04x for the detailed action or document a geographic exception.
- **Supplemental does not mean zoom:** s16x_p03 is actually registered `wide`.
  It fails the shared-world resolution goal, not its declared camera type.
  No frame is labeled `false_zoom` merely because its ID contains `x`.
- **Scene 12:** current closer final revisions improve local action. Keep
  p03/p04 as travel/depth context only if accompanied by p02/x detail views.
  **Scene 14:** inserts read clearly, but incidental cropped Leo/body context
  remains a separate one-actor-contract question; framing success is not a
  technical cast-count pass.
