## Scale and camera interpretation

Milo may occupy different portions of the frame when the viewer/camera is nearer or farther away, changes lens/zoom, or crops differently. Do not call that identity/size drift without accounting for camera and subject depth. At the same camera distance, zoom, crop and standing depth, his dimensions relative to the same local background should remain compatible. The L006–L008 group declares exactly that fixed setup; its actor-position/size variation needs review. Independent scene cuts do not have this same-size requirement.

```bash

```

Open `http://127.0.0.1:8765/` in the VS Code browser and press the audio controls beneath each transcript. Keep the terminal running; Ctrl+C stops it. Alternatively, with the production repository opened as your VS Code folder, run **Tasks: Run Task → Feltwillow: scene review with audio**. Direct HTML previews can restrict local audio; use the HTTP URL. The server serves only this gallery and its referenced media on loopback, with byte-range support for seeking. Audio is the original full-line WAV, not an invented beat-level edit. No audio is uploaded or regenerated.
